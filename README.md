# Wasteland Rivals — Playtest

Windows x64 playable development builds. Unreal Editor is not required.

## Download

Open [Releases](https://github.com/faxicz888/WastelandRivals-Playtest/releases) and download **WastelandRivals-Friends-Playtest-Windows.zip** under Assets. Do not download the automatically generated Source code archive.

1. Extract the entire ZIP to a short path such as `C:\WR` to avoid Windows 'Path too long' errors. Do not launch inside the ZIP.
2. Run `Play-Offline.cmd` for the garage and test drive, or `Play-Bot-Battle.cmd` for an offline 8v8 bot match.
3. For Steam testing, start Steam, then run `Play-WastelandRivals.cmd`. Friends must use the same build.
4. If required, install the included prerequisite from the Prerequisites folder.

## Updates

Download the complete ZIP from the newest release. Close the game and extract into a new short folder. Keep the previous version until the new one works. Preserve your existing `WastelandRivals/Saved` folder; it contains local saves. Save compatibility between prototype versions is not guaranteed. There is currently no automatic in-game updater.

## Current limitations

This is a development prototype. Steam uses test AppID 480 (Spacewar), not a production Wasteland Rivals AppID. Internet multiplayer between separate Steam accounts has not yet been verified. Offline bot matches and local gameplay have been tested; that does not guarantee public matchmaking works.

Report issues with the release version, reproduction steps, and a screenshot. Do not post private account information or tokens.
